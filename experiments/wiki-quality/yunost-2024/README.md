# Сравнение Tesla и OpenWiki: «Юность — 2024»

Обе системы начинают с пустой Wiki и получают одни и те же 145 текстов за
2024 год по Москве, последовательно по месяцам. Общая модель — GPT‑6 Luna
medium через подписку ChatGPT. Платный API исключён.

Tesla сохраняет свой двухстадийный ingest и использует Codex CLI. OpenWiki
сохраняет personal init/update и штатный openai-chatgpt; небольшой патч
совместимости с GPT‑6 Luna раскрыт отдельно.

- [Текущее состояние и живые проверки](SUBSCRIPTION_RUN.md).
- [Протокол и поправка о подписке](PROTOCOL.md), [точная конфигурация](protocol.json).
- [Исследовательская копия инструкций и полный diff](instruction-proposal/README.md).
- [История первоначальных offline проверок](RUNTIME_CHECKS.md).

Корпус, ссылки на исходные строки, цитаты, эталон, логи и версии Wiki хранятся
частно в storage/experiments/yunost-2024. Версия эталона 2 фиксирует общую
проверку Альфредом и одну поправку формулировки; независимой двойной разметкой
она не является. Эталон не передаётся генераторам.

prepare.py выполняет только отбор, фиксацию и проверку снимков, без LLM.
codex_subscription.py --check и обычный запуск openwiki_subscription_check.mjs
выполняют синтетические проверки через подписку. Отдельный study-config включает
у OpenWiki ровно одну закреплённую месячную партию. tesla_run_month.py — такой же
тонкий адаптер для Tesla на Linux. tesla_fixture.py по умолчанию использует
вымышленные ответы; --subscription явно включает настоящий Codex CLI на Linux.
Модели и провайдеры автоматически не переключаются. Перед каждым модельным
запросом проверяется настоящая квота; при остатке ≤10% или неизвестной квоте —
остановка. Синтетические тесты не входят в исследование качества.

Исходный снимок e602df54df7b3ecc07c9 сохранён неизменным. Новый снимок фиксирует
поправки, хеши инструкций, код адаптеров, патч OpenWiki и пользовательскую проверку.
Рабочая Wiki, production canon, ledger, admin DB, расписание и сайт не меняются.

Месячный запуск на сервере: `study_run.py <snapshot> --runtime-config <server-runtime.json>`. До исторической генерации обязательны
его `--check-only` и синтетические проверки `--synthetic openwiki` / `--synthetic tesla`.
Готовность проверяет `prepare.py preflight <snapshot>`. Изоляция использует готовый
Linux bwrap; точная сборка зафиксирована в runtime-lock.json. Порядок берётся из
allocation.json, неудачный шаг сохраняется и останавливает дальнейшее выполнение.
Выполнение только на сервере пользователя, в существующем Tesla checkout;
локальная WSL больше не используется. Runtime config содержит пути, не пароли.
