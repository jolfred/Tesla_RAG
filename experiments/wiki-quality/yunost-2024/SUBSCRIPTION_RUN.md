# Запуск через подписку ChatGPT

Решение Альфреда от 22.10.2026: использовать подписку; для OpenWiki допустимо
штатное подключение к ChatGPT вместо Codex CLI. Платный API не используется.
Модель обеих систем: `gpt-6-luna`, `reasoning.effort=medium`.

## Что проверено живыми вызовами

- Codex CLI 0.163.0-alpha.11: вход ChatGPT и синтетический запрос с JSON Schema.
  Проверка прошла, 1 модельный вызов. Пользовательские config/rules отключены.
- OpenWiki 0.7.2, `6c14bff27830034bfd70c15bde46825d7686ec60`, штатный personal
  init: пустая Wiki, один вымышленный январский текст, 9 запросов, все HTTP 200.
- Штатный personal update: добавлен вымышленный февральский текст; обе встречи
  найдены в результирующих статьях. 16 запросов, все HTTP 200. В каждом запросе
  проверены model, medium и store=false. Проверка настоящей квоты — перед каждым.
- Первый update остановлен после 12 запросов ограничителем синтетического теста.
  Сохранён как незавершённый; повтор начат с исходного январского состояния,
  предел увеличен до 24. Это изменение тестового предела, не промптов метода.
- Подготовлены 13 offline проверок; они проходят. Отдельно проверено, что
  исследовательские инструкции не меняют production canon и admin DB.
  Контрольные суммы вложенного эталона также защищены общим хешем снимка.

Синтетические прогоны не входят в исследовательскую выборку. Даже наличие двух
тестовых фактов не доказывает качество исторической Wiki.

## Ровно что изменено в OpenWiki

Оригинальная версия не знает reasoning-параметр GPT‑6 Luna. Отдельный
`openwiki-luna-compat.patch` добавляет эту модель в таблицу `openai-chatgpt` и
распространяет готовый Luna transport на её точный ID. Код personal ingestion,
промпты, инструменты и организация Wiki сохранены. Исследование должно указывать
**OpenWiki 0.7.2 + раскрытый патч совместимости**, не неизменённый upstream.
Более свежий HEAD `305599f8e44203f9ca6b74bb6b38eebaf0b0405e` проверен:
исправлений этих таблиц в нём нет, поэтому исходный закреплённый commit сохранён.

Сборка использует закреплённый pnpm-lock; отдельно установлен штатный бинарный
модуль better-sqlite3 12.11.1, который отсутствовал после install --ignore-scripts.

## Учёт и секреты

Логи и отчёты находятся в частном `storage/experiments/yunost-2024/working/`:
`subscription-cli-check-v1`, `openwiki-subscription-check-v1/v2/v3`,
`openwiki-subscription-update-v1/v2`. У v1/v2 init было 0 запросов к модели:
не был установлен SQLite-модуль. Успешные init/update — v3 и update-v2.

OpenWiki получает существующую авторизацию Codex только в память процесса.
Заголовки запросов не сохраняются. Проверка успешного update просмотрела файлы
его home на отсутствие access/refresh/id tokens. Разрешён только endpoint
ChatGPT Codex; платные провайдеры и неизвестная квота останавливают тест.
Если осталось ≤10% любого окна, новый вызов запрещён. Сброс квоты не расходуется.

Рабочий эталон `working/user-reviewed-reference-v2` содержит 197 утверждений:
178 основных и 19 дополнительных. Список в целом принят Альфредом; одна явная
поправка: «В февральской публикации Альфред назван командиром „Юности“».
Цитаты и версия 1 сохранены. Это ИИ-черновик с общей проверкой пользователя,
не независимая двойная разметка. Эталон не передавался генераторам.

## Что ещё отделяет проверки от полного эксперимента

Нужны одинаковая изолированная Linux-среда для двух систем, сквозная проверка
нативного Tesla compile через подписку, проверенный порядок всех месячных
обновлений с сохранением контрольных точек и обработкой остановки по квоте.
Windows не используется как основной runner: ранее найдено расхождение CRLF/LF
в штатных проверках хешей Tesla. В подготовке используется отдельная Linux-копия.

Оплаченных API-вызовов нет. Исторические Wiki ещё не построены, оценок качества
и победителя нет. Рабочая Wiki, её ledger, production canon и сайт не меняются.
