# Согласования

1. **Материалы:** Альфред утверждает, отклоняет или заменяет каждый случай из `datasets/candidates-2026-10-20/REVIEW.md`, включая исходную статью и партии публикаций. Сейчас ожидается это решение.
2. **Эталон и методика:** после первого решения готовятся атомарные прежние и новые факты с точными фрагментами источников, список исходных ошибок, правила оценивания и окончательные параметры модели. До явного утверждения запуск запрещён. Для изменяемых исходников сохраняются исходная архивная версия и отдельно экспериментальная редакция с объяснением каждого изменения.
3. **Результаты:** после разрешённого эксперимента предоставляются исходные/полученные статьи, журнал исполнения, оценки и разбор ошибок. Методы при смысловой оценке по возможности скрыты. Исправления разметки сохраняются отдельными версиями с причиной, автором и датой; предыдущие оценки не затираются.

Согласование материалов само по себе не разрешает LLM-вызовы. Отсутствие ответа, истечение срока или подготовка папки не означают согласия.
