# Design System: Летопись Теслы — отрядная википедия (`/wiki`)

Single source of truth для генерации экранов вики в Google Stitch.
Scope: только `/wiki` (каталог `/wiki`, статья `/wiki/<slug>`).
Лендинг и админка — вне scope, остаются тёмными.

Язык: классическая Википедия (Vector) — белая страница, serif-заголовки с
линейками, синие ссылки, инфобокс, содержание, примечания. «Лучше» — за счёт
аккуратной типографики с кириллицей, живых сносок и отсутствия вики-мусора.

Dials: VARIANCE 4 / MOTION 1 / DENSITY 5.

## 1. Visual Theme & Atmosphere

Дневной архив: белая контент-колонка в рамке на светло-сером, сайдбар
навигации слева, подвал с пояснением. Статья: подзаголовок «Материал из
Летописи», serif-заголовок с линейкой, инфобокс справа, содержание боксом,
разделы с линейками, пронумерованные примечания, полоса категорий. Всё
статично — единственный отклик это подчёркивание ссылок при наведении.

## 2. Color Palette & Roles

- **Content White** (#FFFFFF) — колонка статьи и каталога.
- **Page Wash** (#F8F9FA) — фон страницы, инфобокс, содержание, шапки таблиц (#EAECF0).
- **Ink** (#202122) — текст; **Muted** (#54595D) — подписи, подзаголовок.
- **Rule Line** (#A2A9B1) — линейки заголовков, рамки инфобокса/содержания/поиска.
- **Wiki Blue** (#3366CC) — ВСЕ ссылки в статьях (узнаваемость Википедии,
  осознанное исключение из правила одного акцента).
- **Tesla Violet** (#7A3EE6 заливка, #6D28D9 текст) — только хром сайта:
  кнопка «Все статьи», логотип-рамка. Внутри статей фиолетового нет.
- **Alarm Rose** (#B3261E) — только «нет такой статьи» и ошибки загрузки.

## 3. Typography Rules

- **Display:** PT Serif (кириллица обязательна — весь контент русский),
  weight 400: h1 `clamp(28px, 4.6vw, 36px)`, h2 `23px`, оба с нижней линейкой.
  Иерархия — кегль + линейка, не жирность.
- **Body:** системный sans (`Manrope`, fallback `system-ui`) — `16px/1.75`
  в статьях; мера — ширина контент-колонки.
- **Meta:** `12–13px` — подзаголовок, содержание, категории, сноски.
- **Mono:** JetBrains Mono — только слаги в каталоге.
- **Banned:** Inter как основной; градиентный текст; подчёркивание ссылок
  по умолчанию (только по hover).

## 4. Component Stylings

- **Header:** белый, нижняя линейка; логотип 40px + serif-вордмарк;
  поиск — поле + кнопка «Найти» (квадратные углы 2px, как Vector).
- **Sidebar:** текстовые синие ссылки, капс-разделы с линейками:
  Навигация (Заглавная, Случайная статья, на главную), Категории (`имя · счёт`).
- **Infobox:** float right 290px, рамка, сиреневая шапка `#EDE9FE` с названием;
  строки «ключ — значение»; цитаты `(Источник:)` внутри вырезаны.
  Мобильный: в потоке на всю ширину.
- **TOC:** бокс «Содержание», нумерованный список якорей `#раздел`;
  показывать при 2+ разделах.
- **Tables:** рамка, шапка `#EAECF0`, тёмный текст (не акцентный).
- **Footnotes:** sup-маркеры `[n]` в тексте, нумерованный список «Примечания»
  с `↩` назад; wall-ID и локальные пути нигде не показываются.
- **Categories:** полоса «Категории: x» со ссылкой на фильтр каталога.
- **States:** загрузка — текстовая строка; 404 — Alarm Rose строка.

## 5. Layout Principles

- Сетка `190px 1fr`, контент `max-width: 1120px`; статья — естественная ширина
  колонки, инфобокс обтекается текстом.
- Порядок статьи: «← Все статьи» → подзаголовок → h1 → инфобокс → лид →
  содержание → разделы → примечания → категории → пилюля.
- Мобильный: одна колонка, сайдбар сверху, инфобокс в потоке, таблицы —
  горизонтальный скролл в рамке.

## 6. Motion & Interaction

- Статично: hover ссылок — подчёркивание; active кнопок — `scale-[0.98]`.
- Никаких анимаций появления, каскадов, параллакса.

## 7. Anti-Patterns (Banned)

- Никаких эмодзи; никакого Inter как основного; никакого чистого чёрного.
- Никаких свечений, градиентов, тёмных блоков внутри вики.
- Никаких сферических графов «волосатый шар».
- Никаких сырых wall-ID и локальных путей на экране читателя.
- Никаких нефункциональных вкладок («Править», «Обсуждение» без бэка).
- Никаких выдуманных цифр и AI-клише; никаких картинок-заглушек из сети.
