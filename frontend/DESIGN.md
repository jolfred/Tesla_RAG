# Design System: Летопись Теслы — отрядная википедия (`/wiki`)

Single source of truth для генерации экранов вики в Google Stitch.
Scope: только `/wiki` (каталог `/wiki`, статья `/wiki/<slug>`).
Лендинг и админка — вне scope, остаются тёмными.

Dials: VARIANCE 6 / MOTION 2 / DENSITY 5.

## 1. Visual Theme & Atmosphere

Светлый читальный зал архива: тёплая бумага, спокойная editorial-сетка,
никакого неона. Две отдельные страницы: каталог (поиск + список статей) и
страница статьи (мера чтения 760px, таблицы, источники). Навигация — настоящие
ссылки, каждая статья живёт по своему URL. Движения почти нет: поверхность
чтения, не шоу-кейс. Атмосфера — дневной штабной архив: бумага, чернила,
одна фиолетовая печать.

## 2. Color Palette & Roles

- **Paper** (#FAF7F1) — фон страниц вики.
- **Pure Surface** (#FFFFFF) — поиск, каталог, таблицы.
- **Warm Wash** (#F6F1E8) — шапки таблиц, зебра-разделители.
- **Ink** (#211B16) — заголовки, основной текст (#3D352D — текст статей).
- **Muted Fable** (#6F6459) — вторичный текст, подзаголовки.
- **Faint Line** (#E7DFD2) — рамки, разделители (`#EFE9DD` — внутренние линии).
- **Ghost Mono** (#ABA094) — слаги, технические подписи.
- **Tesla Violet** (#6D28D9 текст/контуры, заливка #7A3EE6) — ЕДИНСТВЕННЫЙ
  акцент, brand-locked (фирменный цвет штаба). Плоское использование:
  категории, ссылки, активные чипсы, кнопка «Все статьи» (белый жирный текст).
  НИКОГДА свечения, неоновые тени, градиентные заливки.
- **Alarm Rose** (#B3261E) — только текст ошибок.

Контраст: ссылки и мелкий текст на акценте — только тёмный `#6D28D9`
(на белом 7+:1). Белый текст — только на заливке `#7A3EE6` жирным кеглем.

## 3. Typography Rules

Весь контент — русский: шрифты обязаны поддерживать кириллицу. Это перекрывает
дефолтные рекомендации (Geist/Satoshi/Cabinet кириллицы не имеют).

- **Display:** Unbounded — h1 страницы статьи и заголовок каталога
  (`clamp(28px, 5vw, 46px)`, `line-height: 1.1–1.15`). Иерархия весом, не кеглем.
- **Body:** Manrope (миграция с Inter — Inter забанен как основной) — статьи
  `16px/1.75`, каталог `16px/600`, мера чтения `max-width: 760px`.
- **Meta:** Manrope 800, `11–12px`, `uppercase`, `letter-spacing: 0.08–0.14em` —
  категории, подписи секций.
- **Mono:** JetBrains Mono — слаги в каталоге, даты.
- **Banned:** Inter как основной шрифт; serif; градиентный текст.

## 4. Component Stylings

- **Search:** белое поле, `border-radius: 14px`, рамка Faint Line; фокус —
  контур Tesla Violet, без свечения. Фильтрация мгновенная, локальная.
- **Chips:** пилюли `7px 14px`; неактивный — белый с рамкой; активный —
  подложка `#F1EAFE` + контур и текст Tesla Violet. Формат `категория · счёт`.
- **Catalog:** белый список `border-radius: 18px`, строки разделены Faint Line:
  капс-категория + заголовок + моно-слаг справа. Строка — ссылка целиком.
  Пусто — спокойная строка Muted Fable.
- **Article:** мера 760px; h1 + капс-категория сверху; таблицы в рамке
  `border-radius: 12px`, шапка Warm Wash + Tesla Violet `12px`; `[[ссылки]]` —
  настоящие `<a href="/wiki/slug">` с точечным подчёркиванием; внешние посты —
  «пост VK» (+ нумерация при нескольких); служебный раздел «Источники данных»
  и сырые wall-ID не рендерятся никогда.
- **Back:** «← Все статьи» — текстовая ссылка сверху, залитая пилюля снизу.
- **States:** загрузка — текстовая строка, без спиннеров; 404 — «Такой статьи
  в Летописи нет.» Alarm Rose.

## 5. Layout Principles

- Каталог: контейнер 860px; статья: 760px. Всё по левому краю меры.
- Порядок каталога: кикер → h1 → счётчик → поиск → чипсы → список.
- Порядок статьи: «← Все статьи» → категория → h1 → тело → источники → пилюля.
- Никаких 3-колоночных рядов, никакого `calc()`-математизма — Grid и поток.
- Мобильный: одна колонка, слаг в каталоге скрыть (`< 640px`), таблицы —
  горизонтальный скролл внутри рамки.

## 6. Motion & Interaction

- Почти статично: hover строк — только фон `#FAF7F1`; active — `scale-[0.98]`.
- Никаких каскадов, параллакса, бесконечных циклов. Только `transform`/`opacity`.
- `prefers-reduced-motion` — поведение по умолчанию и так статично.

## 7. Anti-Patterns (Banned)

- Никаких эмодзи; никакого Inter как основного; никаких serif.
- Никакого чистого чёрного; никаких свечений и градиентных кнопок/текста.
- Никаких 3-колоночных равных рядов.
- Никаких сферических графов «волосатый шар» — связи только текстовыми
  `[[ссылками]]`, пока не будет force-layout уровня Obsidian.
- Никаких сырых wall-ID и локальных путей (`../posts/…`) на экране читателя.
- Никаких выдуманных цифр точности и AI-клише («Seamless», «Unleash»).
- Никакого «Scroll to explore»; никаких картинок-заглушек из сети.
- Никаких двух CTA с одним смыслом на экране.
