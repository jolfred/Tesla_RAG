# Design System: Летопись Теслы — отрядная википедия (`/wiki`)

Single source of truth для генерации экранов вики в Google Stitch.
Scope: только `/wiki` (каталог + читалка статей). Лендинг и админка — вне scope.

Dials: VARIANCE 6 / MOTION 3 / DENSITY 5.

## 1. Visual Theme & Atmosphere

Quiet archive reading room, not a dashboard and not a marketing page. Dense with
meaning, calm in motion: двухколоночный исследовательский интерфейс
(каталог слева, статья справа) в глубоком тёмном режиме. Асимметрия — за счёт
сетки 340px / 1fr, а не декора. Всё, что движется, — отклик на действие
пользователя; ничего не пульсирует и не крутится само по себе. Атмосфера —
полуночный штабной архив: тихо, контрастно, по-деловому тепло.

## 2. Color Palette & Roles

- **Void Canvas** (#07060A) — фон страницы. Не чистый чёрный.
- **Raised Surface** (rgba(17,15,24,0.82)) — панели каталога и читалки, `glass-card`.
- **Signal White** (#F2EFFF) — основной текст.
- **Muted Lavender** (#B9B0D6) — вторичный текст, подзаголовки.
- **Ghost Line** (#8E86A8) — плейсхолдеры, пустые состояния, приглушённые подписи.
- **Tesla Violet** (#9D65FF, deep #7A3EE6) — ЕДИНСТВЕННЫЙ акцент, brand-locked
  (фирменный цвет штаба; исключение из запрета на фиолетовый — осознанное,
  не дефолтное). Только плоское использование: активные чипсы, фокусы,
  ссылки, маркеры. НИКОГДА свечения, неоновые тени, градиентные заливки кнопок.
- **Alarm Rose** (#FF9D9D) — только текст ошибок. Больше нигде.

Правила: один акцент на весь экран; тёплые/холодные нейтрали не смешивать;
белый текст на `#7A3EE6` и `#9D65FF` запрещён (контраст) — на акценте только
тёмный текст или акцент только как контур/подложка 12–25% прозрачности.

## 3. Typography Rules

Весь контент — русский: шрифты обязаны поддерживать кириллицу. Это перекрывает
дефолтные рекомендации (Geist/Satoshi/Cabinet кириллицы не имеют).

- **Display:** Unbounded — только заголовок страницы и шапка (`clamp(26px, 4vw, 40px)`,
  `line-height: 1.12`). Иерархия весом, не кеглем.
- **Body:** Manrope (миграция с Inter — Inter забанен как основной) — `14–15px`,
  `line-height: 1.65–1.7`, `max-width: 65ch` в читалке.
- **Meta:** Manrope 800, `10–12px`, `uppercase`, `letter-spacing: 0.08–0.14em` —
  категории, подписи секций.
- **Mono:** JetBrains Mono — слаги, даты, счётчики.
- **Banned:** Inter как основной шрифт; любые serif (вики — не editorial-глянец);
  градиентный текст на заголовках.

## 4. Component Stylings

- **Search:** одно поле, `border-radius: 14px`, фон Raised Surface, контур
  `rgba(122,62,230,0.4)`; фокус — контур Tesla Violet, без свечения.
  Плейсхолдер Ghost Line. Фильтрация мгновенная, локальная.
- **Chips (категории):** `border-radius: 999px`, `7px 13px`; неактивный —
  прозрачный с белой рамкой 14%; активный — подложка `rgba(122,62,230,0.25)`
  + контур Tesla Violet. Формат `категория · счёт`.
- **Catalog:** плоский список, не карточки: строка = капс-категория + заголовок
  `14px/600`. Активная строка — подложка 25% violet. Скролл внутри колонки
  (`max-height: 560px`). Пусто — строка Ghost Line «Ничего не найдено».
- **Reader:** панель `border-radius: 18px`, паддинг `clamp(18px, 3vw, 32px)`.
  Заголовки статьи `24px` / `17px`; таблицы — шапка Tesla Violet `12px`,
  строки с нижней рамкой `rgba(255,255,255,0.07)`; вики-ссылки `[[..]]` —
  кнопки-пунктир `#B79CFF`; внешние ссылки — тот же цвет, открываются в новой
  вкладке; блок «Источники» отделён верхней линией 25% violet.
- **States:** загрузка — текстовая строка («Открываем статью…»), без спиннеров;
  ошибка — Alarm Rose текст в панели; пусто — спокойная подсказка Ghost Line.

## 5. Layout Principles

- Сетка `340px 1fr`, `gap: 14px`, контейнер `max-width: 1120px`, шапка страницы
  `max-width: 760px`, выравнивание влево. Центрированных hero-блоков нет.
- Порядок сверху вниз: шапка (логотип 44px + «← На главную») → заголовок +
  счётчик статей → поиск → чипсы → каталог/читалка.
- Каталог — единственная прокручиваемая колонка; читалка растёт по контенту.
- Никаких 3-колоночных рядов, никакого `calc()`-математизма во флексах —
  только Grid. Абсолютное позиционирование — только декоративный фон.
- Полноэкранных секций нет; правило `min-h-[100dvh]` — на корне страницы.

## 6. Motion & Interaction

- Motion restrained: переходы `transform`/`opacity` до `0.25s`, без spring-хореографии
  (поверхность чтения, не шоу-кейс). Hover на строках каталога — только смена
  подложки. Active — `-translate-y-[1px]` / `scale-[0.98]`.
- Никаких бесконечных циклов, параллакса, scroll-hijack, staggered-каскадов.
- `prefers-reduced-motion` — поведение по умолчанию и так статично, отдельных
  веток не требуется.

## 7. Anti-Patterns (Banned)

- Никаких эмодзи в интерфейсе.
- Никакого Inter как основного шрифта; никаких serif.
- Никакого чистого чёрного `#000000`.
- Никаких свечений, неоновых теней, градиентных кнопок и градиентного текста.
- Никаких 3-колоночных равных рядов карточек.
- Никаких сферических графов связей «волосатый шар» (пройдено: круговые
  раскладки узлов визуально лгут) — связи только текстовыми `[[ссылками]]`,
  пока не будет force-layout уровня Obsidian.
- Никаких выдуманных цифр точности и AI-клише («Seamless», «Unleash», «Next-Gen»).
- Никакого «Scroll to explore» и стрелок-шевронов.
- Никаких внешних картинок-заглушек; изображения только из бандла или статей.
- Никаких двух CTA с одним смыслом на экране.
